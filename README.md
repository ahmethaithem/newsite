# NEVADA

متجر NEVADA هو تطبيق تجارة إلكترونية عربي بسيط مبني بـ Next.js App Router و TypeScript و Tailwind CSS. يدعم تصفح المنتجات، السلة المحلية، تثبيت الطلبات بدون تسجيل دخول، الدفع عند الاستلام، ولوحة إدارة محمية بكلمة مرور لتأكيد الطلبات وتصديرها بصيغة Excel مطابقة لقالب شركة الشحن.

## المتطلبات

- Node.js 20.18 أو أحدث
- مشروع Supabase
- حساب Vercel للنشر

## التشغيل المحلي

1. ثبّت الحزم:

```bash
npm install
```

2. انسخ ملف البيئة:

```bash
cp .env.example .env.local
```

3. أضف القيم التالية في `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
ADMIN_PASSWORD=
ADMIN_SESSION_SECRET=
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

لا تستخدم `SUPABASE_SERVICE_ROLE_KEY` في المتصفح. التطبيق يستخدمه فقط داخل الخادم.

4. شغل التطبيق:

```bash
npm run dev
```

افتح `http://localhost:3000`.

## إعداد Supabase

1. أنشئ مشروعاً جديداً في Supabase.
2. افتح SQL Editor.
3. شغّل ملف الهجرة:

```text
supabase/migrations/20260902000000_nevada_initial_schema.sql
```

4. لتجربة التصدير، يمكنك تشغيل:

```text
supabase/seed-dev-orders.sql
```

يتضمن ملف البذور طلباً تجريبياً لبغداد وطلباً للبصرة. يصدّر ملف الشحن اسم المحافظة العربي المحفوظ مع الطلب، ولا يصدّر الشفرة الداخلية.

## لوحة الإدارة

- رابط الدخول: `/admin/login`
- كلمة المرور تأتي من `ADMIN_PASSWORD`
- الجلسة تحفظ في Cookie موقعة وآمنة و HttpOnly

من صفحة `/admin/orders` يمكن البحث، التصفية، تعديل معلومات التوصيل، تعديل مبلغ التحصيل، تأكيد الطلب، تجهيزه للشحن، إلغاؤه، وتصدير الطلبات المؤكدة غير المصدرة.

## المنتجات والصور

تعديل المنتجات يتم من:

```text
src/data/products.ts
```

استبدال الصور يتم داخل:

```text
public/products/model-1/
public/products/model-2/
public/products/model-3/
public/products/model-4/
```

الصورة التي تحتوي `main` هي صورة البطاقة الأساسية، وبقية الصور تظهر في معرض صفحة المنتج.

## استقبال الطلبات

المتصفح يرسل معرف المنتج والقياس واللون والكمية فقط. الخادم يتحقق من الحقول بـ Zod، ينظف أرقام الهاتف كنصوص، يطابق المحافظة مع القائمة المعتمدة، يعيد حساب الأسعار من `src/data/products.ts`، ثم يحفظ الطلب والقطع في Supabase.

## تصدير Excel للشحن

من لوحة الإدارة:

1. أكد الطلب أو اجعله جاهزاً للشحن.
2. حدد الطلبات المؤهلة أو اختر تصدير كل الطلبات المؤكدة غير المصدرة.
3. نزّل ملف `.xlsx`.
4. ارفع الملف مباشرة إلى نظام شركة الشحن.

الملف يستخدم قالب `PrimeUploadSample.xlsx` ويحافظ على رؤوس الأعمدة العربية التسعة بالترتيب A-I. يبدأ كل طلب في صف مستقل من الصف 2، ويحفظ رقم الهاتف كنص، ومبلغ التحصيل والعدد كقيم رقمية، ولا يصدّر أرقام الطلبات أو الشفرات الداخلية أو أي أعمدة إضافية.

يمكن إعادة تنزيل الدفعات السابقة من `/admin/exports` بدون إنشاء دفعة جديدة.

## الاختبار

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

الاختبارات تغطي ربط المحافظات، أرقام الهاتف، حساب المجاميع، أهلية التصدير، تطابق قالب Excel، ترتيب الأعمدة التسعة، أنواع الخلايا، وتجميع تفاصيل وكمية المنتجات في صف واحد لكل طلب.

## النشر على Vercel

1. ارفع المشروع إلى مستودع Git.
2. اربط المستودع مع Vercel.
3. أضف متغيرات البيئة نفسها في إعدادات المشروع على Vercel.
4. اجعل `NEXT_PUBLIC_SITE_URL` هو رابط Vercel النهائي.
5. نفذ الهجرة في Supabase قبل استقبال الطلبات الحقيقية.
6. انشر التطبيق.

بعد النشر، ادخل إلى `/admin/login` وتأكد من ظهور لوحة الطلبات.
